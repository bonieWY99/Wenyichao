# 實證護理概論｜114-2

亞洲大學護理學系實證護理課程學習網站。此儲存庫提供可獨立執行的靜態網站，學生使用不需要 ChatGPT 帳號。

## 學習內容

- 實證護理 5A 路徑、18 週課程地圖與評量。
- 1A、2A、3A 分組工作區與各階段／總成果 PDF 列印匯出。
- PICO、PubMed／Cochrane／Embase／華藝 CEPS 搜尋歷程與跨資料庫 PRISMA 彙整。
- CASP 2024 RCT 與 SR／MA 評讀、官方提示及中文翻譯、V／I／P 總結。
- OCEBM 2011 Level 1–5 參考；一般／放大字體與淺／深色模式。

## 啟用 GitHub Pages

1. 開啟本儲存庫 **Settings → Pages**。
2. Source 選 **Deploy from a branch**。
3. Branch 選 **main**，資料夾選 **/ (root)**，按 **Save**。
4. 等待 GitHub 顯示已發布網址，再提供給學生。

根目錄已包含 index.html、所有相對路徑 CSS／JS 及 .nojekyll，不需要安裝依賴、輸入 API key 或執行建置。

## 作業與附件

學生輸入存在目前瀏覽器的 localStorage；PRISMA 圖片、Word、PDF 附件存在本機 IndexedDB，依組別隔離。這不是雲端共同編輯或教師集中收件系統。

學生應匯出 PDF 並繳交到學校教學平台。Word／PDF 附件原檔須另外下載繳交；JSON 備份不包含附件。更換裝置、網域或清除瀏覽器資料前，請先備份。新 GitHub Pages 網址不會自動帶入舊網站的瀏覽器作業。
