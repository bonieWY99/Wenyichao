# 九單元系統隨機練習

## iPhone 使用方式

使用 Safari 開啟 GitHub Pages 網址，點選「分享」→「加入主畫面」。日後從主畫面的「成人護理練習」圖示開啟，即會以 App 式全螢幕介面執行；首次成功開啟後，核心頁面與題庫可供離線載入。

## 我的紀錄

每次交卷後，系統會將作答時間、學生資料、分數、題目、各選項、學生答案與正確答案自動儲存在同一台裝置的瀏覽器資料中。可由首頁「我的紀錄」回看。紀錄不會同步到其他裝置，清除 Safari 網站資料也會一併清除。

學生填寫學號、姓名與班級，選擇系統後每回隨機抽 20 題，交卷即時計分為 100 分制；可重抽下一回並下載個人 JSON 練習紀錄。

每題僅依「主要考點」編入一個單元；交叉概念僅留作後端次要標籤，避免以題幹零星關鍵詞誤入其他題池。題目來自考選部護理師國考內外科護理學 106–115 年資料，保留官方題目連結。
